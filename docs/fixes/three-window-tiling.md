# 三窗口自适应平铺优化方案（v0.2.15）

## 已复现的问题

2026-10-16 的实际运行环境为 1920×1080、125% 缩放，工作区 1920×1030。
三扇登录窗口的实际外框均为 618×898，但规划器按保守边框估算为 625×918。
窗口间距与屏幕两侧留白均为 13 个物理像素，三列需要 `3×625 + 4×13 = 1927`
像素，仅超出工作区 7 像素就退化为两列层叠。第三扇位于 `(346,73)`，相对
第一扇 `(311,38)` 仅向右下移动 35 像素，几乎完全覆盖。

直接调用当前 `Registry::reserve/place` 的离线回放得到完全相同的坐标；两窗
不重叠断言通过，三窗不重叠断言失败。正常定位日志也明确记录 `layered=true`，
因此不是并发调度超额、旧缓存或 Windows 未执行定位。

## 优化策略

1. **保留安全边框估算。** Windows、macOS、GTK 的装饰尺寸与隐藏窗口测量时序
   不同；不把本机测得的较窄边框硬编码成全平台常量，也不改变原生事件等待逻辑。
2. **在层叠之前寻找可用的平铺方案。** 按批次预计容量枚举列数，保留完整窗口
   高度及原有多行能力；优先维持默认宽度和默认间距，其次缩小间距，最后缩窄窗口。
   同等尺寸下优先较大的间距，再优先更多列，保持已有正常布局不变。
3. **限定收缩边界。** 默认间距 10 个逻辑像素，最低 6 个逻辑像素；客户区默认宽
   480、最低宽 420 个逻辑像素，按目标显示器缩放统一换算成物理像素后再计算。
   不为塞入更多行而额外压缩窗口高度，避免验证码区域过矮；单窗适配小工作区的
   原有高度保护继续生效。
4. **确实放不下再层叠。** 所有可读平铺方案均失败时，沿用原有屏内层叠算法，
   不向屏外新增行。保留固定槽位、预计容量、补位不移动旧窗口及主动整理行为。
5. **增强诊断。** 布局日志保留实际外框和位置，并补充规划外框、工作区及缩放，
   以后可以直接区分规划误判与原生尺寸差异，不记录邮箱、授权链接或凭据。

本次场景预期无需缩小客户区：保留规划宽度 625，只把物理间距从 13 调为 11，
三列连同两侧留白共需 `3×625 + 4×11 = 1919` 像素，即可完整并排。

## 实施与验收

- 先提交到工作区的回归断言，确认旧算法在 1080p / 125% 三窗及小屏三窗用例失败。
- 实现纯几何规划，确保本机原有正常两窗布局不发生尺寸或坐标变化。
- 覆盖不同分辨率、缩放、负坐标工作区、间距与最小宽度边界，以及三窗补位/整理。
- 本机运行独立 Rust 几何模块测试、轻量 JavaScript 回放与国际化/版本静态检查；
  不在本机构建安装包，不操作真实注册流程，不替换正在运行的程序。
- 推送后由 GitHub Actions 完整校验 Windows、macOS、Linux X11 和 Wayland；
  沿用空白原生窗口回归，X11 / Wayland 各连续八轮。纯几何缩放矩阵不冒充
  原生混合缩放多屏实测。
- 同步 package、Tauri、Cargo、锁文件及发布工作流到 v0.2.15。功能校验通过后
  推送不可变标签，构建 Windows 安装版/便携版、macOS Universal、Linux DEB/AppImage；
  所有构建通过、附件版本/状态/大小/摘要核对后才公开发布，不覆盖旧版本附件。

## 防止再次漏测

“每扇窗口都在屏内”不等于“能够平铺时没有相互遮挡”。新增断言直接检查任意
两扇规划矩形不相交，并验证可读平铺条件成立时不进入层叠；原有屏内可见性、
槽位稳定性和真实窗口事件回归仍保留。

## 本机验证记录

- 修复前，第一轮新增回归共有 5 项失败，直接捕获三窗矩形相交、小屏及最小宽度
  边界；原有正常双窗用例通过。
- 修复后，14 项独立 Rust 几何/槽位测试全部通过，包括 5 组分辨率、5 档缩放、
  1–5 并发的可读网格矩阵，以及既有可见性矩阵。
- 重跑分析阶段的原始回放：三窗变为 `(11,56)`、`(647,56)`、`(1283,56)`，
  均未启用层叠且客户区宽度保持 480；两窗仍为 `(328,56)`、`(966,56)`。
- 28 项 JavaScript 注册回归、中英文各 453 个词条检查通过；所有发行版本字段
  均为 0.2.15，差异空白检查通过。
- 这些结果不代替三平台完整 Rust/原生窗口校验和正式附件构建，远端通过后才发布。

最终校验和发行记录随 [v0.2.15 发布说明](https://github.com/fujunchao/zcode-pool/releases/tag/v0.2.15) 保存。
